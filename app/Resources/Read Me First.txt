Printer Studio KH — Read Me First
=================================

WHAT THIS IS
------------
A menu bar app that keeps this Mac's shared printers reachable from other
Macs and iOS devices — and that can set up an HP Laser 107a, a USB-only
printer Apple has no driver for, so every device on your network can print
to it.

The app lives in the menu bar as a small printer icon. Click it to open
Printer Studio KH, to fix shared queues, or to quit.


OPENING IT THE FIRST TIME — PLEASE READ
---------------------------------------
This app is not sold through the App Store, so the first time you open it
on a Mac that received it over AirDrop, Telegram, email or a download,
macOS will refuse. It may say the developer "cannot be verified", or it may
say the app "is damaged and can't be opened. You should move it to the
Trash."

Either way, this is the fix. Open Terminal (in Applications > Utilities),
paste this line, and press Return:

    xattr -cr "/Applications/Printer Studio KH.app"

Then open the app normally. That is the whole procedure, and you only do
it once per Mac.

You may have seen advice to right-click the app and choose "Open" instead.
That works for some of these warnings and does nothing at all for others —
and when it does nothing, there is no button anywhere, including in System
Settings, that will get you past it. The command above always works, so
use that.

It is safe. It removes only macOS's marker recording that the file arrived
over a network. It changes nothing inside the app itself, and it is the
same thing the "Open Anyway" button does when macOS offers one.

Why this is necessary: Apple only removes these warnings for apps signed
with a paid Apple Developer account and notarized by Apple. Without that,
this one step is the price. It cannot be done from inside the app, because
the warning appears before the app is allowed to run at all.

AFTER IT OPENS
--------------
Nothing else needs doing by hand. The app can:

  * show every printer on this Mac, and whether it is shared
  * keep shared queues open to the network — the fix for "Job held for
    authentication" on other Macs — either on demand or automatically in
    the background
  * install the HP Laser 107a driver, create its print queue and share it.
    macOS will ask for your password once, because installing a printer
    driver needs administrator rights.

The driver is bundled inside this app. There is nothing else to copy.


SENDING THIS APP TO ANOTHER MAC
-------------------------------
Send the app on its own. It carries this file inside it, so there is no
separate Read Me to send.

On the receiving Mac, run the one-line command near the top of this file,
once. That is the only setup step.

After that the driver install works normally. The app deliberately clears
the "downloaded from the internet" flag from the driver files as it
installs them — without that step, macOS would quietly refuse to run the
newly installed driver, and print jobs would sit there doing nothing. That
is handled for you.


TROUBLE?
--------
Open the app and look at the Activity tab. It says in plain English what
it did, and what went wrong if something did.

For a fuller picture you can also run the diagnostic report that ships
alongside this app in the project folder:

    ./app/report.sh && ./dist/printer-studio-report


AFTER A RESTART (1.0.1)
-----------------------
Open Settings and turn on “Keep the USB printer ready after restarts” once.
macOS asks for administrator permission to install a small background service.
It saves no password. After that, it releases your configured HP Laser 107a
automatically at boot and after a USB replug, checking every 15 seconds.
New printer setup includes this service in its existing administrator approval.

The menu bar icon starts at login by default. You can turn either feature off
in Settings. The USB service works without opening the app. Network AirPrint
advertising still starts when the sharing user logs in. This app does not
change Mac login, FileVault, or privacy settings.


AIRPRINT SETUP (1.0.6)
----------------------
In Sharing, turn on Print from iPhone and iPad. This also enables Printer
Sharing if it is off; macOS may ask for administrator approval. If approval
fails or is cancelled, setup stops and Activity explains why. Share at least
one printer, then reopen your phone's print dialog on the same network.
An installed advertisement alone cannot accept jobs while sharing is off.

PAPER AND STICKER SIZES (1.0.3)
-------------------------------
Open Paper & Sticker Sizes. The list includes 30 x 40, 50 x 70 and 70 x 100 mm,
A5 (148 x 210 mm), A4 (210 x 297 mm), and common label sizes. Dimensions show
both millimetres and inches (in); edit width and height in millimetres. You can edit or
switch off any entry. Width and height follow the stock's feed orientation.

For label printers, install the correct driver and add the printer on each
Mac first. Check the limits shown, then press Apply to printers and approve
the change. Only supported sizes are added. Reopen the phone's print dialog;
its size choices depend on the app and iOS version as well as the printer.

A4 and A5 already appear on the HP Laser queue. The HP Laser 107a cannot feed
30 x 40, 50 x 70 or 70 x 100 mm loose labels: its minimum sheet is 76 x 127 mm.
Use a compatible label printer for those, or laser-compatible labels on a
supported sheet. A narrow thermal label printer cannot take A4 or A5 stock.
Driver checks do not replace a real test with the correct stock loaded.

On Printers, save the name you want and select the exact paper or label size
loaded in each printer. Applying custom sizes adds choices; selecting a size
sets that printer’s default. Reopen the Mac or iPhone print dialog and choose
the same size there. A job can override the default, so check it before printing.
Print test page sends one short PDF page at the selected size, one copy, with
no banner sheets. For labels, test with one label and stop on a mismatch.

If printing fails, use Settings > Copy Error Report and paste it when asking
for help. It includes each queue’s accepted formats, driver filter, default
size, and advertised sizes. No administrator password is needed to copy it.
