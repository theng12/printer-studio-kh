- [ ] **The sidebar jumps when it is clicked, and several buttons do the same** — owner report 2026-11-27; 1.0.49 fixes the measured movement. Measured in the real `MainWindow` at 860x580 and 1024x720: selecting every sidebar row moves nothing; a running action made the footer grow 23 pt and the list shrink 23 pt, and a result banner pushed the page down by its own height. The busy line now replaces the status text in the footer's always-present row, and the banner floats over the page. `app/test-sidebar-stable.sh` fails if any nav row, the list, the footer or the page moves across every selection, a busy action and a banner. **Shipping in 1.0.49.**
- [ ] **AirPrint from an iPhone to the HP Laser 107a does not work** — owner report 2026-11-27; the failing step is measured and the app now names it. From this Mac against the owner's shared queue (`office-imac-blue-m1-8-256`, 192.168.0.77): discovery, advertise and ACL all pass (the bridge record resolves; port 631 answers a plain remote IPP client; the queue is shared with no per-user ACL; a remote PDF `Validate-Job` returns `successful-ok`). The print fails: a PDF `Print-Job` sent as an iPhone sends it was accepted and stuck at `processing` with `printer-state-message = "The printer is offline."` and reasons `offline-report,connecting-to-device`; `retry-job` keeps it waiting instead of failing it. The app already knew how to fix that state but said only "Enabled". 1.0.49 carries CUPS's reason into the Sharing page and Overview, names the cause, and offers the matching fix (release from macOS's USB service, keep it ready, or check the cable/network). **Still unproven: a page printed from a real iPhone.** The device was offline at test time, so the print itself must be watched after it is back.
- [ ] **Setup and first use are stiff and hard to follow** — owner report 2026-11-27; 1.0.49 adds the guided path. Overview now opens with "Start here": plug in, set it up, share it with the phone, then print a test page — in order, each line turning green from live state with the one button that does the step. Settings points to it, and the setup page's steps use plainer words. **Shipping in 1.0.49.**
